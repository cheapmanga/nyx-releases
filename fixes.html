Get protected and online games running

Nyx installs the game and keeps it on the current build. Some titles need one more step to play online or to get past anti-tamper. That step is a fix.

A manifest installs the game. A fix makes it playable.

Adding a game with Nyx writes the files Steam needs, and Steam downloads it from its own servers. That's enough for most single-player games. Anything that phones home (multiplayer, a publisher launcher, or anti-tamper like Denuvo) needs a matching fix on top.

Online fixes
Let a multiplayer or co-op game connect and play with others who run the same fix. This is what makes online play work on an added game.
Launcher bypasses
Skip a publisher's own launcher (Ubisoft Connect, EA, Rockstar) so the game starts straight from Steam instead of asking you to sign in elsewhere.
Denuvo and anti-tamper
The hardest case. Denuvo ties a game to a licence check, and a fix removes that check. Coverage is limited and arrives later than other fixes; some titles have none.

Install first, fix second

Let the game install and reach its current build before you apply a fix: a fix patches files that have to exist already.

  1. 1Add and install

    Add the game via Nyx, restart Steam if asked, and let it finish downloading.

  2. 2Open Fixes

    On the game's store page, open the Nyx icon and choose Fixes to see what's available for it.

  3. 3Apply and launch

    Apply the fix, let Steam restart if prompted, then launch. For online games, everyone in your group needs the same fix.

Not every game has a fix. A fix can also break when the game updates, and a new build may need a newer one. Single-player titles are the safe bet; online Denuvo games are the least likely to work. Without a fix the game still installs and updates fine, it just can't do the online or anti-tamper part yet.
