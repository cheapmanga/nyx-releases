Fixes & online play

Get protected and online games running

Nyx installs the game and keeps it on the current build. Some titles need one extra step to play online or to get past anti-tamper — that step is a fix.

Get Nyx first
The short version

A manifest installs the game. A fix makes it playable.

Adding a game with Nyx writes the files Steam needs and downloads it from Steam's own servers. That's enough for most single-player games. Anything that phones home — multiplayer, a publisher launcher, or anti-tamper like Denuvo — needs a matching fix on top.

◍

Online fixes

Let a multiplayer or co-op game connect and play with others who run the same fix. This is what makes “play online” work on an added game.

⤿

Launcher bypasses

Skip a publisher's own launcher (Ubisoft Connect, EA, Rockstar) so the game boots straight from Steam instead of asking you to sign in elsewhere.

◆

Denuvo & anti-tamper

The hardest case. Denuvo ties a game to a licence check; a fix removes that check. Coverage is limited and comes later than other fixes — some titles have none.

How to apply

Install first, fix second

Always let the game install and reach its current build before applying a fix — a fix patches files that have to exist already.

Add & install the game

Add it via Nyx, restart Steam if asked, and let it finish downloading so it's on the latest build.

Open the Fixes menu

On the game's Steam store page, open the Nyx icon and choose Fixes. Nyx shows what's available for that title.

Apply and launch

Apply the fix, let Steam restart if prompted, then launch. For online games, everyone in your group needs the same fix.

Honest caveat. Not every game has a fix, and a fix can break when the game updates — a new build may need a newer one. Single-player titles are the safe bet; online Denuvo games are the least likely to work. When there's no fix yet, the game still installs and updates fine, it just can't do the online or anti-tamper part until one exists.
